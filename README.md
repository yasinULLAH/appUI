# Missing Person Alert UI - Sample Project

A professional, mobile-first web interface designed for high-impact "Missing Person" emergency alerts. This project serves as a high-fidelity template for government agencies, NGOs, or families to broadcast critical information quickly and professionally.

## 🚀 Live Demo
- **Standard Version:** [index.html](https://yasinullah.github.io/appUI/index.html)
- **Advanced Govt Version:** [index2.html](https://yasinullah.github.io/appUI/index2.html)

---

## 🛠 Features

### 1. Standard UI (`index.html`)
*   **Classic Design:** A clean, professional layout suitable for general community alerts.
*   **Responsive:** Fully functional on mobile and desktop.
*   **Custom Siren Icon:** Hand-crafted SVG siren for immediate visual recognition.

### 2. Advanced Government Alert (`index2.html`)
*   **High-Fidelity Aesthetic:** Designed with a "State Emergency Broadcast" look, utilizing massive typography and authoritative color palettes (Emergency Red, Police Navy, Warning Gold).
*   **Interactive Calls:** Integrated `tel:` links for instant dialing of family and police helplines.
*   **Native Social Sharing:** Functional "Share Alert" button using the Web Share API (Mobile native menu / PC Clipboard).
*   **SEO & AEO Optimized:** Fully equipped with Open Graph (OG), Twitter Cards, and Schema.org JSON-LD structured data to ensure visibility on social media and in AI search engine results.
*   **Dynamic Animations:** Subtle CSS-based strobe and pulse effects to draw attention without distracting from the data.

## ⚙️ Customization

To use this for a new alert, simply edit the following sections in the HTML files:

1.  **Subject Data:** Update the name, father's name, age, and last seen location in the "Dossier" section.
2.  **Images:** Replace `person.png` (Subject Photo) and `UI.jpeg` (Poster Thumbnail).
3.  **Metadata:** Update the `og:url` and `og:image` absolute paths in the `<head>` to match your own hosting domain (e.g., GitHub Pages or a custom domain) to ensure social previews work correctly.
4.  **Helplines:** Update the `href="tel:..."` links with the correct contact numbers.
